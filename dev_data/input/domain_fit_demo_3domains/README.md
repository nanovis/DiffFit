The volume map file, `density2.mrc`, 
is from https://github.com/builab/DomainFit/tree/main/example. 

In `subunits_cif` are 3 demo structures to search from. 

The whole demo library is at https://osf.io/download/vgk7f/. 

The data is generated by following this guide: 
https://github.com/builab/DomainFit/blob/main/example/example.md. 

Of note is that we generated 359 PDB files by following DomainFit's Steps 1-3, 
instead of the mentioned 344 files.

The files under "subunits_cif" folder are derived (split) from 
AlphaFold Protein Structure Database (https://alphafold.ebi.ac.uk/download), 
which is available for academic and commercial use, 
under a CC-BY-4.0 (https://creativecommons.org/licenses/by/4.0/) licence.
