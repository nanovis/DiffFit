Tool: DiffFit

DiffFit is a tool for rapid differentiable fitting of molecular atomic moles to a Cryo-EM map on a CUDA-compatible GPU. It can fit a single model in an interactive mode or multiple models in a "disk" mode by specifying the file path. Documentation, installation guide, tutorial, code, and more will be updated at https://github.com/nanovis/DiffFit.
